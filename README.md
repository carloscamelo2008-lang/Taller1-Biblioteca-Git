# Sistema de Gestión de Biblioteca

Taller 1 - Programación de Computadores III - UPC

## Autor

Carlos Eduardo Camelo Montaño

## Descripción

Aplicación de consola desarrollada en Java para gestionar clientes, libros y préstamos de una biblioteca.

La información se almacena en memoria utilizando `ArrayList`.

## Cómo ejecutar

1. Abrir el proyecto en IntelliJ IDEA.
2. Compilar el proyecto con Maven.
3. Ejecutar `Main.java`.

## Funcionalidades

- CRUD de clientes.
- CRUD de libros.
- Registro de préstamos.
- Devolución de préstamos.
- Listado de préstamos.
- Menú principal por consola.
